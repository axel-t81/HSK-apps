# HSK Apps

Small, self-contained projects for studying Chinese, preparing for HSK exams, and following China business topics.

## Projects

| Project | Description |
|---|---|
| [HSK 1 Anki Deck](hsk1-anki/) | A 300-word HSK 3.0 Band 1 deck with recognition and production cards, curated pinyin and translations, and optional audio. |
| [HSK 1 Listening Audio](hsk1-listening/) | Ten standalone 30-word MP3 listening tracks with translations, example sentences, and transcripts. |
| [China Business Digest](china-business-digest/) | A direct-source news collector and daily bilingual email about Chinese bookkeeping, small business, and tax obligations. |

## Repository layout

Each project lives in its own directory and contains its own README, source files, and runnable outputs.

```text
hsk-apps/
├── README.md
├── china-business-digest/
├── hsk1-anki/
└── hsk1-listening/
```

## Contributing

Keep projects independent and document how to run them in each project README. Do not commit credentials, local configuration, virtual environments, downloaded source archives, personal agent guidance, or unnecessary generated caches.
